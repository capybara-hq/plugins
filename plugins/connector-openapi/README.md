# @capybara-hq/plugin-connector-openapi

OpenAPI connector (connector@1): one tool per operation of an OpenAPI 3.0 / 3.1 HTTP API.

## Icon

`icon.svg`: the OpenAPI Initiative logo (owner: the OpenAPI Initiative (The Linux Foundation)), downloaded on
2026-11-08 from the OpenAPI Initiative style guide, https://github.com/OAI/OpenAPI-Style-Guide at
667578102402 (graphics/vector/OpenAPI_Logo_Pantone.svg and OpenAPI_Logo_White.svg). It is a
trademark of its owner, used only to identify the service this plugin connects to; the plugin is not
affiliated with or endorsed by the owner. The artwork is unchanged except for removing editor
metadata and setting a square viewBox; the lettering is omitted, as the style guide allows where a
purely graphical representation is required, and it shows the color version on light backgrounds and
the white version on dark ones.
