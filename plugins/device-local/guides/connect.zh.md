# 连接本机

在你自己的电脑上使用的设备：电脑用 `capybara-device` 程序连接到平台并为这台设备服务，由你在本机限制它能做什么。请在要连接的电脑的终端里依次执行下面的步骤（macOS 或 Linux，Node 22.12 或更高版本；Windows 请使用 WSL）。

## 1. 安装连接程序

```bash title="安装 capybara-device"
npm install -g @capybara-hq/device@next
```

## 2. 登录

```bash title="登录到这个平台"
capybara-device login --url {{publicUrl}}
```

命令会在浏览器里打开一个页面（加上 `--no-browser` 时，它会打印地址和一个验证码，可在任意已登录的浏览器里输入）。在页面上选择组织，选择 **本机**，再选择新建设备，或选择你已连接的某台设备把它移到这台电脑。用另一台电脑登录到同一台设备时，会替换掉原来的电脑。

## 3. 保持在线

```bash title="开机自动连接（推荐）"
capybara-device service install -c <device id>
```

这就是 `login` 在结尾打印的命令（带着你的设备 id）：它会安装服务并立即启动，之后每次登录都会自动连接。也可以运行 `capybara-device start -c <设备 id>` 在前台连接，直到你停止它。程序连接后设备显示为在线；离线时智能体无法使用它。

**如果这台电脑已经连接了其他平台或组织。** 这台电脑服务的每台设备对应一个连接，以设备 id 保存，各有自己的服务。在浏览器里选择新建设备，或把另一台电脑上的设备移到这里，都会新增一个连接；重新登录这台电脑已在服务的设备，则沿用原来的连接（只更新登录凭据；若已安装它的服务，接着运行 `capybara-device service restart -c <设备 id>`）。有多个连接时，每条命令都需要加 `-c <设备 id>`（设备名称或主机名唯一时也可以用它们）；只有一个连接时可以省略 `-c`。`capybara-device status` 会列出所有连接及其 id，`login` 的结尾会打印带有 id 的下一步命令。

## 它能做什么

命令在你电脑上的沙箱里运行，位于设备目录（`~/capybara-device/<设备 id>`）内。你在本机设置所有者上限：`capybara-device ceiling show -c <设备 id>` 查看，`capybara-device ceiling set -c <设备 id>` 修改（是否允许在沙箱外运行、网络、项目范围），每个连接各有一份。新连接默认允许在沙箱外运行：请求在沙箱外运行的调用按会话的权限模式审批；`--outside-sandbox off` 让每个调用都留在沙箱内。组织和平台的设置同样生效，以最严格的为准。OS 模式下命令以你的用户身份运行，没有 CPU 和内存限制。

删除设备会撤销这台电脑的登录并停止程序，文件仍保留在你的电脑上。
