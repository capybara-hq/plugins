# @capybara-hq/plugin-connector-mcp

MCP connector (connector@1): tools and resources of remote MCP servers over Streamable HTTP.

(docs/favicon.svg and docs/logo/light.svg / dark.svg, the logos of modelcontextprotocol.io). It is a
trademark of its owner, used only to identify the service this plugin connects to; the plugin is not
affiliated with or endorsed by the owner. The artwork is unchanged except for removing editor
metadata and setting a square viewBox; it draws the favicon's mark without its tile, black on light
backgrounds and white on dark ones as in logo/light.svg and logo/dark.svg.
