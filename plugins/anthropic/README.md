# @capybara-hq/plugin-anthropic

Anthropic model provider (model-provider@2) using the official SDK and the native Messages API.

## Icon

`icon.svg`: the Anthropic symbol (owner: Anthropic), downloaded on 2026-11-08 from the Anthropic press kit,
https://www.anthropic.com/press-kit (Anthropic media resources, "Anthropic symbol - Slate.svg" and
"Anthropic symbol - Ivory.svg"). It is a trademark of its owner, used only to identify the service
this plugin connects to; the plugin is not affiliated with or endorsed by the owner. The artwork is
unchanged except for removing editor metadata and setting a square viewBox; it shows the Slate
variant on light backgrounds and the Ivory variant on dark ones.
