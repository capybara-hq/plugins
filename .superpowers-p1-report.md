## Proxy mode behavior

| Mode | Host check | Ports | HTTP | CONNECT | SOCKS5/4a | IP literals | Private / metadata by resolved IP |
|---|---|---|---|---|---|---|---|
| `open-public` (default) | public DNS shape; `ALLOW_HOSTS` ignored | any 1-65535 | yes | yes | yes | allowed when public | refused |
| `allowlist` | must match `ALLOW_HOSTS` (exact or `*.x`) | any 1-65535 | yes | yes | yes | refused | refused |
| none (provider, empty allowlist) | no proxy container; `NetworkMode: none` | loopback only | no | no | no | — | — |

## Provider mapping

| `limits.network` | `limits.mode` recorded | Container |
|---|---|---|
| `{ kind: "open-public" }` | `auto` / `sandbox` | internal network + proxy `MODE=open-public`, any public host/port |
| `{ kind: "allowlist", hosts: [...] }` | `auto` / `sandbox` | internal network + proxy `MODE=allowlist`, those hosts/any port |
| `{ kind: "allowlist", hosts: [] }` | `auto` / `sandbox` | `NetworkMode: none`, no proxy, no proxy env |
| absent (old kernel) | `sandbox` | same as empty allowlist (safe direction) |
